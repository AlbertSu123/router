How fair usage works

Raw tokens show recorded input, cache writes, and output. Cached input is included in input and is shown separately. Pressure-weighted tokens count at 25% in windows with only one recorded Router user. When multiple people need the same quota window, the weight rises with pressure, up to 100% when it fills. Every request uses the highest weight in its applicable quota windows, including demand and pressure observed later in the same window.

Scores remain provisional until those windows reset. Usage with unknown quota pressure stays separate; it is never treated as free. Tokens are an activity measure, not a bill or an exact share of the provider’s quota. Different models and cache hits can consume quota differently.

Only requests through Router after personal sign-in are recorded. Direct sessions, other apps, and usage before setup are not attributed. Incomplete streams may contain partial token counts. Subscription access expires within an hour without renewed verification.
